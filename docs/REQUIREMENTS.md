# 要件定義

kobito-tools シリーズのクリップボード履歴アプリの要件です。Paste の代わりとして、それ以上に使えることを目指します。

アプリ名は **Pastephant**（paste ＋ elephant。「象は決して忘れない（An elephant never forgets）」から、コピーした物を忘れない象）です。

## 1. 前提

| 項目 | 決定 |
|---|---|
| 対応OS | macOS 13 以降（Apple Silicon / Intel のユニバーサルバイナリ） |
| 実装 | Swift ネイティブ（SwiftUI ＋ AppKit）。PopNote! と同じく `build.sh` と `swiftc` でビルド（Xcode プロジェクトは作らない） |
| 同期 | しない。iCloud や他の端末との同期はなし |
| 保存 | 履歴はすべてこのMacの `~/Library/Application Support/Pastephant/` に保存（SQLite ＋ 生データはファイル）。クラウドに上がらず、Macごとに別の履歴になる（→ 6章） |
| 基準パス | 任意。指定すると、共有タグ（`.kobito-tools/Tags/tags.json`）と Tomelet への書き出し（`.kobito-tools/Pastephant/`）に使う。履歴の保存には使わない |
| 画面 | 画面の右端から出てくる縦のリスト。右か左かは設定で切り替え（→ 3章） |
| ネットワーク | 使わない。LaTeX の描画もオフラインで行う |
| 配布 | PopNote! と同じ（公証なし、Releases で zip、`xattr` の案内） |

## 2. 必要な権限

| 権限 | 使う機能 | 無いとき |
|---|---|---|
| アクセシビリティ | ペースト（`⌘V` の送信）、ペーストスタック中の `⌘V` の検知 | 項目をクリップボードに戻すだけにし、ペーストはユーザーに任せる。初回に案内を出す |
| 画面収録 | 使わない（OCR はコピーされた画像にだけ行う） | — |

## 3. 画面

### 3.1 履歴パネル

```text
                                   ┌──────────────────────┐
                                   │ 🔍 検索…      ⇅  ⚙  │
                                   │──────────────────────│
                                   │ PowerPoint  #論文 図形 │ ← プレビュー（選んでいる行、
  （作業中のアプリ。                │  ┌────────────────┐  │    カーソルを当てている間はその行）
    フォーカスは移らない）          │  │  [図形の画像]   │  │    作業中は、その画面
                                   │  └────────────────┘  │    （タグ・編集・変換・まとめる・
                                   │ 09/28 14:05・コピー2回 │     数式・定型文・キーの一覧）
                                   │──────────────────────│
                                   │ 📌 ピン・定型文        │
                                   │   署名                 │
                                   │ 🕘 履歴               │
                                   │ ▶ 図形 3 個 PowerPoint │ ← 選択中
                                   │   \int_0^1 f(x)dx  数式│
                                   │──────────────────────│
                                   │ ⏎ 貼る ⇧⏎ プレーン …  │
                                   └──────────────────────┘
                                         画面の右端に張り付く
```

- グローバルショートカット（初期値 `⌥⌘V`、変更可能）で、設定した側の端からスライドして出てきます。もう一度押すか `Esc` を押す、またはパネルの外をクリックすると閉じます。
- **フォーカスを奪わない** `NSPanel`（`.nonactivatingPanel`）を使います。ペースト先のアプリはアクティブなまま、キー入力だけをパネルが受け取ります。
- 画面を広く使わないよう、**1つのパネルの上部をプレビュー、その下を一覧**にします。プレビューは枠（カード）で囲み、その下辺に貼り方の帯を付けて、一覧との境目をはっきりさせます。
- 見た目は kobito-tools シリーズに合わせます（紙の色の地、小人の墨色の文字、アイコンの青みがかった灰色のアクセント。暗い画面にも対応）。一覧の1件はカードにし、左の帯で色分けします（コピー元のアプリ・種類・最初のタグ・なし。色は PopNote! のタグと同じハッシュでシリーズの色から選ぶ）。
- パネルの内側の縁に、象の耳の小人がしがみつき、ゆっくり揺れます（パネルの子ウィンドウでクリックは下へ通す。左端のときは反転。設定で隠せる）。
- 設定の画面でパネルの幅・出る側・プレビュー・色分け・小人を変えている間は、実物のパネルを画面の端に出したままにし、変えるたびにすぐ反映します（設定を閉じると隠れる）。作業の画面（タグ・編集・変換・まとめる・数式・定型文）は、プレビューの場所に出します。
- 出てくる側（右か左か）、幅、どのディスプレイに出すか（マウスのある画面 / メインの画面）、プレビューを出すかは設定で変えられます。
- 各行には種類のアイコンかサムネ、見出し（テキストの冒頭 / 定型文とピンの名前）、コピー元のアプリのアイコン、経過時間、タグを表示します。
- プレビューには中身（文字はスクロール・選択でき、画像は大きく、ファイルは場所）と、コピー元・日時・回数・大きさ・タグ・型の一覧を出します。`⌘Y`（検索が空なら `Space` も）で Quick Look も開けます。

### 3.2 キー操作

たくさんのショートカットを覚えなくても使えるよう、**覚えるキーは3つ**にします。ほかのキーは、覚えた人が速く使うためのものです。

| キー | 動作 |
|---|---|
| `⏎` | いま選んでいる**貼り方**で貼る |
| `⇥` / `⇧⇥` | 貼り方を切り替える |
| `→`（`⌘K`・右クリック） | その項目に**できること**の一覧を開く |

- **貼り方の帯**：プレビューの下に、選んだ項目の中身に合う貼り方だけを並べます（文章なら改行を消す・句読点、表なら LaTeX・Markdown・CSV、ファイルならパス、画像なら画像の文字、数式なら LaTeX の式、保存した変換の組み合わせ）。選んだ貼り方で**実際に貼られる内容をプレビューに出し**、貼る前に確かめられるようにします。ほかのクリップボード管理アプリとの違いはここです。
- **できることの一覧**：その項目で使える操作だけを、1文字のキー付きで並べます（`C` コピーだけ・`T` タグ・`P` ピン・`E` 編集・`M` まとめる・`R` 変換・`L` 数式・`K` スタック・`S` Tomelet・`N` / `A` PopNote!・`Q` Quick Look・`F` 定型文・`D` 削除・`?` キーの一覧）。`⌘` は押さずに、その文字だけで実行します。各行の右に `⌘` のショートカットを小さく出し、使ううちに覚えられるようにします。
- 画面の下の案内は、いまの画面で使うキーだけを出します（一覧では「⏎ 「そのまま」で貼る・⇥ 貼り方・→ できること・⌘/ キー」）。

| 覚えると速いキー | 動作 |
|---|---|
| `↑` `↓` / `⌃N` `⌃P`（`⇧` で複数選択） | 選択を移動 |
| 文字の入力 | そのまま検索欄に入る |
| `⌘1`〜`⌘9` / `⌃1`〜`⌃9` | 上から N 番目を貼る / 保存した変換の組み合わせ N で貼る |
| `⌘⏎` / `⇧⏎` / `⌥⏎` | コピーだけ / プレーンで貼る / 改行を消して貼る |
| `⌘T` `⌘E` `⌘P` `⌥⌘↑↓` `⌘L` `⌘M` `⌘N` | タグ・編集・ピン・ピンの並べ替え・数式・まとめる・定型文 |
| `⌘S` / `⌘⇧N` / `⌥⌘⇧N` | Tomelet に残す / PopNote! の新しいメモ / 開いているメモに足す |
| `⌘Y`（検索が空なら `Space`） / `⌘⌫` | Quick Look / 削除 |
| `⌘/` / `⌘,` / `Esc` | キーの一覧 / 設定 / 戻る・検索を消す・閉じる |

## 4. 機能要件

### F-01 履歴の取得

- `NSPasteboard.general.changeCount` を 0.3 秒ごとに見て、変わったら取得します。
- 1回のコピーに含まれる**全ての `NSPasteboardItem` の、全ての型（UTI）とデータ**を保存します。複数の項目があるコピー（Finder で複数のファイルを選んだときなど）も、その構成のまま保存します。
  - パワポの図形群、Excel のセル範囲、Keynote のオブジェクト、RTF/HTML の書式付きテキスト、画像、ファイル参照などが、元のアプリへ**元の形のまま**戻せることを受け入れ条件とします。
  - アプリ独自の型も捨てずに保存します。
- 一緒に記録する情報：コピーした日時、コピー元のアプリ（コピーされた瞬間の最前面のアプリの bundle ID と名前）、代表の種類、プレビュー用のテキストとサムネ。
- 代表の種類：`text` / `richText` / `image` / `file` / `url` / `color` / `office`（パワポなど独自の型が主）/ `formula`（F-06 で作ったもの）。
- **重複の扱い**：全ての型のデータから計算したハッシュが同じなら新しい項目を作らず、既存の項目を先頭に移して「コピーした回数」を増やします。
- 自分がクリップボードに書いたもの（ペーストのために戻したときなど）は、独自の型 `io.github.kobito-tools.pastephant.own` を付けておき、履歴に二重に入れないようにします。
- 1項目の上限を設定します（初期値 100MB）。超えた項目は、プレビューだけを残して生データは保存しません。一覧でもそれとわかるように表示します。

### F-02 取得しないもの（プライバシー）

- `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` が付いたものは保存しません（1Password などのパスワード管理アプリ）。
- 除外するアプリの一覧（初期値：キーチェーンアクセス、主なパスワード管理アプリ）。
- メニューバーから「一時停止」できます（再開するまで、または指定した時間だけ）。

### F-03 ペースト

- 選んだ項目をクリップボードに書き戻し、アクセシビリティ経由で `⌘V` を送ります。パネルは先に閉じ、元のアプリにキーが届いてから送ります。
- 書き戻したあと、ペースト前のクリップボードに戻すかどうかは設定で選べます（初期値：戻さない）。
- **プレーンテキストで貼る**：`public.utf8-plain-text` だけを載せます。
- **改行を消して貼る**：F-07 の「改行を消す」と同じ処理です。

### F-04 タグ

- 1つの項目に複数のタグを付けられます。候補の出し方と新しいタグの作り方は PopNote! の `⌘T` と揃えます。
- タグは**シリーズ共通のタグ**を使います。基準パスを指定していれば `<基準パス>/.kobito-tools/Tags/tags.json` を正本とし、このMacのDBの `tags`・`tag_categories` 表はその写しです。同期の規則は Tomelet の `docs/BASE_PATH_FOR_COMPANIONS.md` 4章（PopNote! の `TagStore.swift`）と同じです。
  - 基準パスを指定していないときは、このMacのDBだけでタグを管理します。後から指定すると、同期の規則で `tags.json` とまとめます。
  - タグは完全には削除せず、アーカイブだけにします（シリーズの規則）。
- パネル上部の絞り込みで、タグを選んで表示できます（複数選んだときは AND）。
- **コピー元のアプリで自動タグ付け**：「アプリ → タグ」の対応を設定しておくと、コピーした時点で付きます（例：Overleaf、TeXShop → `#latex`）。コピー元のアプリはブラウザのタブまでは見分けられないため、ブラウザの場合は URL を含むテキストの**ドメインで判定する**規則も選べます。

### F-05 検索と並べ替え

- 検索の対象：テキスト、OCR で読み取った文字（F-08）、タグ、コピー元のアプリ名、ファイル名、LaTeX の元の式。
- SQLite の FTS5 で全文検索します。日本語でも見つかるように、trigram トークナイザを使います。
- 絞り込みの書き方：`#タグ`、`type:image`、`app:PowerPoint`、`is:pinned`、`after:2026-09-01`。
- 並べ替え：最後に使った日時（初期値）/ コピーした日時 / 使った回数 / 種類 / コピー元のアプリ。

### F-06 LaTeX → 数式画像

- `⌘L` か、メニューバーから開く入力欄に LaTeX の式を書くと、その場でプレビューします。`⏎` で画像を作って貼ります。
- 選んだテキストの項目が LaTeX の式に見えるとき（`$...$`、`\[...\]`、`\frac` など）は、変換メニューからそのまま画像にできます。
- 描画には **KaTeX をアプリに同梱**し（MIT ライセンス）、WKWebView で描きます。KaTeX が対応していない命令は、エラーの場所を表示します。
- クリップボードに載せる型：**PDF（ベクター）＋ PNG（Retina 解像度）＋ TIFF**。
- オプション：文字色、文字の大きさ（pt）、背景（透明 / 白 / 任意の色）、インライン / ディスプレイ、余白。設定はよく使う組み合わせを「プリセット」として保存できます（例：「暗いスライド用（白文字）」）。
- **元の式を埋め込む**：PDF のメタデータ、PNG の `iTXt` チャンク、独自の型 `io.github.kobito-tools.pastephant.latex` の3か所に元の式とオプションを入れます。
  - 履歴の数式の項目から、元の式を開き直して直せます。
  - 作った画像がほかのアプリからコピーされて戻ってきたときも、埋め込まれた式を読み取り、`formula` として扱います。
- よく使う式やマクロ（`\newcommand`）は設定に登録でき、全ての式の前に付けて描画します。

### F-07 貼る前の変換メニュー

`Tab` で開きます。変換したものを貼るだけで、元の項目は変えません。

| 変換 | 内容 |
|---|---|
| 改行を消す | 日本語の行どうしはそのままつなぎ、英語の行どうしは半角スペースを入れる。行末のハイフネーションを直す（`inter-⏎national` → `international`。`e-⏎mail` のように元からハイフンがある語は、macOS の `NSSpellChecker` で判断。つないだ語が辞書にあればハイフンを消し、無ければ残す）。空行（段落の区切り）を残すかは設定で選べる |
| 句読点の変換 | `、。` ↔ `，．` |
| 全角・半角の統一 | 英数字と記号を半角に、カタカナを全角に（それぞれ選べる） |
| 空白を消す | 前後の空白、連続する空白、行末の空白 |
| 大文字・小文字 | 大文字 / 小文字 / 先頭だけ大文字 |
| 表の変換 | Excel などからコピーした表（TSV、または HTML の `<table>`）を、**LaTeX の `tabular`** / Markdown の表 / CSV に変換 |
| 引用 | 各行の先頭に `> ` を付ける |
| 箇条書き | 各行の先頭に `- ` / `・` / `1.` を付ける |
| 数式画像にする | F-06 へ |
| パスとして貼る | F-12 へ |

- 変換はいくつかを続けてかけられます（例：改行を消す → 句読点の変換）。よく使う組み合わせは名前を付けて保存し、ショートカットを割り当てられます。

### F-08 画像の文字認識（OCR）

- 画像の項目は、保存したあと裏で Vision フレームワーク（`VNRecognizeTextRequest`、日本語・英語）にかけ、読み取った文字を検索の対象にします。
- 変換メニューの「文字として貼る」で、読み取った文字をテキストとして貼れます。
- 処理が重いときは待ち行列に入れ、コピーの取得を止めないようにします。

### F-09 ピン留めと定型文（スニペット）

- 履歴の項目をピン留めすると、一覧の先頭の「ピン」の欄に固定され、自動で消える対象から外れます。
- 定型文は新しく作ることもできます。次の差し込みに対応します。

| 差し込み | 内容 |
|---|---|
| `{date}` `{date:yyyy/MM/dd}` | 今日の日付（書式を指定可） |
| `{time}` | 今の時刻 |
| `{clipboard}` | 今のクリップボードのテキスト |
| `{cursor}` | 貼ったあとのカーソルの位置（`←` を送って戻す） |

- ピンの並び順は `⌥⌘↑` `⌥⌘↓` で変えられます（一覧のドラッグは F-13 の「取り出す」に使うため）。

### F-10 貼る前に編集

- `⌘E` でその場で編集できる欄を開き、`⌘⏎` で貼ります。
- 編集したものは新しい項目として履歴に入ります（元の項目は残します）。

### F-11 複数の項目を1つにまとめる

- 複数選んで `⌘M` を押し、区切り（改行 / 空行 / 読点 / カンマ / 任意の文字列）を選ぶと、1つのテキストにして貼るか、新しい項目として保存します。
- 並びは選んだ順です。

### F-12 ファイルをパスとして貼る

- Finder でコピーしたファイルを、次のいずれかで貼れます：絶対パス / `~` を使ったパス / 指定した基準フォルダからの相対パス / ファイル名だけ / `file://` の URL。
- 複数のファイルの場合は改行でつなぎます。
- ファイルの項目は**パス（とブックマーク）を記録するだけ**で、中身はコピーしません。ファイルが消えた・移動したときは一覧で薄く表示します。

### F-13 ドラッグ＆ドロップで取り出す

- パネルの行をドラッグして、ほかのアプリにドロップできます。保存してある全ての型をドラッグに載せます。
- 複数選んでドラッグしたときは、文字を改行でつないだ物を載せます（1回のドラッグで渡せるのは1つの項目のため）。

### F-14 ペーストスタック（順番に貼る）

- グローバルショートカット（初期値 `⌃⌘C`）でスタックモードを始めます。始めると画面の端に小さな「スタック N 件」の表示が出ます。
- スタックモードの間にコピーしたものは、順番にスタックに積まれます（履歴にも入ります）。パネルから複数選んで「スタックに入れる」こともできます。
- スタックモードの間は、`⌘V` を押すたびに**積んだ順に1つずつ**貼られます。CGEventTap で `⌘V` を検知し、貼られたのを待ってから次の項目をクリップボードに載せます。
- 最後まで貼るか、もう一度ショートカットを押すと終わります。「逆の順番に貼る」も設定で選べます。

### F-15 消える期限

- 種類ごとに保存期間を設定できます（初期値：テキスト 無期限、画像 30日、office 30日、ファイル参照 90日）。
- 履歴の件数の上限と、生データの合計容量の上限（初期値 5GB）も設定できます。超えたら、古くてピン留め・タグのない物から消します。
- ピン留めしたもの、タグの付いたものは消しません（タグ付きも消すかは設定で選べます）。
- 設定画面に今の容量を表示し、「今すぐ整理」ボタンを置きます。

### F-16 PopNote! に送る

- 選んだ項目から、PopNote! の新しいメモを作ります（テキストは本文、画像は添付）。PopNote! が開いていれば、今開いているメモに追加することもできます。
- 選んだ項目の文字と画像（PNG）を一時ファイル（`$TMPDIR/Pastephant-PopNote/<UUID>.json`、`format: "pastephant-clip"`）に書き、`popnote://import?file=<パス>` で PopNote! に渡します。PopNote! はこのフォルダのファイルだけを読み、読んだら消します（PopNote! 側に追加済み）。

### F-17 Tomelet に残す

- `⌘S` で選んだ項目を、Tomelet の基準パスに書き出します。**その日の分を1つのメモにまとめます**。
  - 見出しは「09月28日のクリップ」とし、その日の最初の書き出しでメモを作ります。2回目以降は同じメモの末尾に追記します（メモの ID を覚えておきます）。
  - 1項目ごとに、時刻・コピー元のアプリ・タグの行と本文（テキスト、LaTeX の式、ファイルのパス、OCR の文字）を書き、区切り線でつなぎます。画像はアップロードとして添付し、本文から参照します。
  - メモの作成日時はその日の最初の書き出しの時刻、メモのタグは項目のタグをまとめたものにします。
  - 日付の区切りは、項目を**書き出した日**で判断します（コピーした日ではありません）。
- 書き出し先は `<基準パス>/.kobito-tools/Pastephant/` です。シリーズの規則（1つのSQLiteを2つのアプリから書き込まない）に従い、Tomelet や PopNote! のDBには書き込みません。
  - `database/pastephant.sqlite3`：Tomelet の `memos` 表と同じ形の表を持つDB。PopNote! と同じく、Tomelet の `migrations/*.sql` の写し（`schema/tomelet/`）をファイル名順に適用して作ります。PRAGMA も同じ（`foreign_keys=ON`・`journal_mode=DELETE`・`synchronous=FULL`・`busy_timeout=5000`）。
  - `uploads/`：メモに添付する画像。
  - `lock.json`：使用中の印（`app: "pastephant"`、30秒ごとに更新、2分で期限切れ）。別のPCの印が有効な間は書き出さず、「『PC名』で使用中です」と案内します。
- Tomelet は PopNote! のメモと同じように、このDBを**読み取り専用**で開いて表示します（→ 8章）。
- 「このタグが付いたら自動で残す」という規則も設定できます。
- 書き出した項目には印を付け、二重に書き出さないようにします。

### F-18 OpenSesame! からの呼び出し

- URL スキーム `pastephant://` で、次の操作をアプリの外から呼べるようにします。OpenSesame! に登録すれば1キーで使えます。

| URL | 動作 |
|---|---|
| `pastephant://open` | 履歴パネルを開く |
| `pastephant://open?tag=論文` | タグで絞り込んで開く |
| `pastephant://latex` | LaTeX 入力を開く |
| `pastephant://stack/toggle` | ペーストスタックを始める / 終える |
| `pastephant://pause` | 取得を一時停止 / 再開 |

### F-19 メニューバーと設定

- メニューバーのアイコンから、パネルを開く、LaTeX 入力、一時停止、スタック、設定、終了を選べます。Dock には出しません（`LSUIElement`）。
- ログイン時に起動（`SMAppService`）。
- 設定の項目：ショートカット、パネルの出る側・幅・ディスプレイ、除外するアプリ、自動タグの規則、保存期間と容量、LaTeX のプリセットとマクロ、変換の組み合わせ、ペースト後にクリップボードを戻すか、基準パス。
- 基準パスの候補として、Tomelet がこのMacで開いている基準パス（`~/Library/Application Support/TickTockTome/config/setting.json`）を示します。

## 5. 非機能要件

| 項目 | 目標 |
|---|---|
| パネルの表示 | ショートカットを押してから 100ms 以内に表示 |
| 検索 | 履歴 10万件で、1文字打つごとに 50ms 以内に結果を更新 |
| 取得 | コピーから 0.5 秒以内に履歴に入る（OCR やサムネ作りは後回し） |
| 待機中の負荷 | CPU 使用率 はほぼ 0%、メモリ 100MB 以下 |
| 起動 | ログイン時の起動で、ほかのアプリの邪魔をしない |
| データの安全 | このMacの履歴DBは WAL で保存（基準パスに置く書き出し用DBはシリーズと同じ DELETE モード）。生データは一時ファイルに書いてから名前を変えて置く。アプリが落ちても履歴が壊れない |
| 送信 | 外部への通信をしない |

## 6. 保存の設計

```text
~/Library/Application Support/Pastephant/
├── database/history.sqlite3   項目・型の一覧・タグの写し・全文検索
├── blobs/ab/abcdef….bin       生データ（中身のハッシュ名。同じデータは1つだけ）
├── thumbs/<項目ID>.png        一覧用のサムネ
└── settings.json              このMacの設定（ショートカット、パネル、保存期間、基準パスなど）
```

基準パスを指定したときに使う場所（シリーズ共通。Tomelet の `docs/BASE_PATH_FOR_COMPANIONS.md`）：

```text
<基準パス>/.kobito-tools/
├── dataset.json                    読むだけ（無ければ PopNote! と同じ手順で作る）
├── Tags/tags.json                  共有タグ（F-04）
└── Pastephant/                     Tomelet への書き出し（F-17）
    ├── lock.json
    ├── database/pastephant.sqlite3 Tomelet の memos 表と同じ形
    └── uploads/
```

主な表（詳しくは `schema/` で決めます）：

| 表 | 内容 |
|---|---|
| `clips` | ID、代表の種類、プレビューのテキスト、コピー元のアプリ、コピーした日時、最後に使った日時、使った回数、ピン、並び順、全体のハッシュ、Tomelet に書き出したか |
| `clip_representations` | どのクリップの何番目の `NSPasteboardItem` の何番目の型（UTI）か、生データのハッシュ（`blobs/` の名前）、大きさ |
| `tag_categories`, `tags` | 共有タグの写し（ID は文字列。Tomelet・PopNote! と同じ形） |
| `clip_tags` | 項目とタグの対応と、その付け方（手動 / 自動） |
| `snippets` | 定型文 |
| `clip_search` | FTS5（テキスト、OCR の文字、LaTeX の式、ファイル名、アプリ名） |

- 生データは中身のハッシュを名前にしているので、同じ画像を何回コピーしても容量は1つ分です。使われなくなった生データは、整理のときに消します。
- 履歴は基準パスに置きません。基準パスに書くのは F-17 の「残す」を選んだ物だけです。

## 8. ほかのアプリ側で必要になるかもしれない変更

- **PopNote!**（実装済み）：`popnote://import?file=…` の受け口（`PopNoteApp.swift`）と、文字と画像をメモに入れる `window.PopNote.importClip`（`web/app.js`）を加えました（F-16）。
- **Tomelet**（実装済み）：`scripts/popnote-memos.js` を `mirrorCompanionMemos` に広げ、PopNote! のメモと一緒に `pastephant.sqlite3` のメモを読み取り専用で写します。表示するかは PopNote! と同じように一度だけ尋ね、`settings.showPastephantMemos` に保存します（設定画面にも切り替えを追加）。画像は `Pastephant/uploads/` からも配信し、Pastephant のメモを開くと `pastephant://open?query=exported:<日付>` を呼びます。`docs/BASE_PATH_FOR_COMPANIONS.md` に 5a章を加えました。
